# Security Policy

U512 is security-sensitive mathematical software.

## Supported versions

Security fixes are provided for the latest published release. Consumers should
pin immutable release tags and review release notes before upgrading.

## Reporting

Suspected vulnerabilities should be reported through a private GitHub security
advisory in this repository:

https://github.com/Paym4It/U512/security/advisories/new

Do not disclose an unpatched vulnerability in a public issue.

## Assurance status

The unit, fuzz, invariant, reference-vector, integration, Anvil, and RSK
validation suites provide engineering evidence. They are not a professional
security audit or formal proof, and no such claim is made.
